# PAX MUNDI — гранд-стратегия альтернативной истории

Браузерная песочница в духе AI-гранд-стратегий: **любая держава, любая эпоха — и полная свобода переписать историю**. Игра ведёт симуляцию на собственном детерминированном движке (экономика, дипломатия, войны — всё в цифрах), а ИИ-модель можно опционально подключить для нарратива.

## Чем отличается от жанровых аналогов

| Проблема жанра | Решение в Pax Mundi |
|---|---|
| Нет экономических метрик | ВВП-индустрия, казна, доход/мес, население, технологии — всё в числах и графиках |
| Договоры теряются в чатах | **Реестр договоров**: тип, стороны, дата, статус, кто нарушил |
| Мир «плывёт» через 15–40 ходов | Детерминированное ядро: состояние мира не противоречит само себе |
| Долгая генерация и токены | Ходы мгновенные и бесплатные; ИИ — опция, а не зависимость |
| Успех зависит от скорости печати | Структурированные действия + свободные указы (парсятся офлайн) |

## Геймплей

- **Песочница эпох**: 117 н.э. (Рим), 1100, 1700, 1914, 1936, 1946, 1991, 2025 — граница любой страны в любой из эпох.
- **Дипломатия**: отношения −100…+100, репутация, договоры (ненападение, торговля, гарантии, союз), ИИ-нации с 8 типами характера, которые помнят обиды, заключают и нарушают договоры, вступаются за союзников.
- **Войны**: коалиции, оккупации регионов, истощение поддержки войны, капитуляция с уступкой территорий и репарациями.
- **Внутренняя политика**: налоги, инвестиции, пропаганда, стабильность, восстания и эпидемии.
- **Советник**: анализ угроз, возможностей и экономики.
- **Сохранения**: автосейв + ручной слот (перемотка истории).
- **Локализация**: русский и английский.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшен-сборка в dist/
```

## Опциональный ИИ-нарратив

В игре: ⚙️ Настройки → укажите API-ключ (OpenRouter или любой OpenAI-совместимый эндпоинт). Тогда свободные указы будут обрабатываться языковой моделью (нарратив + структурированные распоряжения). Без ключа игра полностью автономна.

## Архитектура

```
src/
  data/       карта мира (world-atlas → ISO3), смежность, эпохи-снапшоты, данные стран
  sim/        движок: создание мира, экономика, ИИ наций, войны, события
  ui/         React-компоненты: карта (SVG, пан/зум), панели, экраны
  llm.ts      опциональная интеграция с языковыми моделями
  i18n.ts     локализация RU/EN
```

Код игры — оригинальный. Картографическая основа — Natural Earth (public domain, пакет `world-atlas`).
